/**
 * LeetCode 309. Best Time to Buy and Sell Stock with Cooldown
 * -----------------------------------------------------------------
 * QUESTION:
 * You are given an array `prices` where prices[i] is the price of a
 * given stock on day i.
 *
 * Find the maximum profit you can achieve. You may complete as many
 * transactions as you like (buy one and sell one share of the stock
 * multiple times) with the following restrictions:
 *   - After you sell your stock, you cannot buy stock on the next
 *     day (i.e., there is a cooldown of 1 day).
 *   - You may not engage in multiple transactions at the same time
 *     (i.e., you must sell the stock before you buy again).
 *
 * Example:
 *   prices = [1,2,3,0,2]
 *   Output: 3
 *   Explanation: transactions = [buy, sell, cooldown, buy, sell]
 *                profit = (2-1) + (2-0) = 3
 * -----------------------------------------------------------------
 * APPROACH: State Machine DP (rolling variables, O(1) space)
 *
 * On any given day, we can be in exactly one of 3 states:
 *
 *   1. held  -> we are currently holding a stock at the end of today
 *   2. sold  -> we just sold our stock today (so tomorrow is cooldown)
 *   3. reset -> we are not holding stock and are free to buy today
 *               (either never bought yet, or our cooldown period is over)
 *
 * Each variable stores the MAX PROFIT achievable while ending the day
 * in that state.
 *
 * Transitions when processing today's price `p`:
 *
 *   sold  = held + p
 *           -> to end today "sold", we must have been holding
 *              yesterday and sold today
 *
 *   held  = max(held, reset - p)
 *           -> to end today "held", either we were already holding
 *              and did nothing, OR we were free (reset) yesterday
 *              and bought today
 *
 *   reset = max(reset, prevsold)
 *           -> to end today "reset" (free to buy), either we were
 *              already free yesterday and did nothing, OR our
 *              cooldown from yesterday's sale (day before) just ended
 *
 * IMPORTANT ORDER OF OPERATIONS:
 *   - `held` must use YESTERDAY's `reset` value (not today's), so it
 *     is computed before `reset` is updated -> naturally correct
 *     since we update sold, then held, then reset, in that order.
 *   - `reset` must use the sold value from BEFORE today's update
 *     (i.e., yesterday's sold), so we cache it in `prevsold` before
 *     overwriting `sold`.
 *
 * Base cases (before day 0 / no stock history yet):
 *   sold  = -infinity  (impossible to have sold with 0 days processed)
 *   held  = -infinity  (impossible to be holding with 0 days processed)
 *   reset = 0           (0 profit, not holding anything, free to buy)
 *
 * Answer: max(sold, reset)
 *   -> the best final profit is either ending in "sold" state or
 *      "reset" state (never end while still "held", since an unsold
 *      stock isn't realized profit)
 *
 * Time Complexity:  O(n)
 * Space Complexity: O(1)
 * -----------------------------------------------------------------
 */
class Solution {
    public int maxProfit(int[] prices) {
        // Initial states: haven't processed any day yet
        int sold = Integer.MIN_VALUE;  // can't have sold with no history
        int held = Integer.MIN_VALUE;  // can't be holding with no history
        int reset = 0;                 // free to buy, 0 profit so far

        for (int p : prices) {
            // Cache yesterday's "sold" before it gets overwritten,
            // since today's "reset" depends on it (cooldown just ending)
            int prevsold = sold;

            // Today "sold": we were holding yesterday, sell at price p
            sold = held + p;

            // Today "held": keep holding, or buy today using yesterday's
            // "reset" (free) state
            held = Math.max(held, reset - p);

            // Today "reset": stay free, or cooldown from 2 days ago's
            // sale just ended (prevsold = yesterday's sold state)
            reset = Math.max(reset, prevsold);
        }

        // Final answer must be in "sold" or "reset" state
        // (ending with "held" means unrealized profit, so it's excluded)
        return Math.max(sold, reset);
    }
}
