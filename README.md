# 💡 LeetCode Solutions (Pattern-Wise)

A curated collection of my personal [LeetCode](https://leetcode.com/) problem solutions, organized systematically by algorithmic patterns to master data structures and algorithms. Every solution here is written and implemented by me.

---

## 📂 Repository Structure

The repository is structured pattern-by-pattern to streamline revision and highlight core algorithmic concepts:

- **`BackTracking/`**: Permutations, combinations, subsets, and constraint satisfaction problems.
- **`Binary search/`**: Efficient searching on sorted arrays and search space reduction.
- **`binary search tree/`**: BST traversals, validations, and node manipulations.
- **`Dynamic programming/`**: Overlapping subproblems and optimal substructure solutions (e.g., Decode Ways).
- **`Greedy/`**: Optimization problems making locally optimal choices.
- **`Hashing/`**: Frequency maps, hash sets, and O(1) lookup problems.
- **`Heap,PQ/`**: Priority queues, K-element problems, and merging patterns.
- **`LinkedList/`**: Pointer manipulation, reversal, and cycle detection.
- **`Queue/`**: FIFO data structure problems and applications.
- **`Recursion/`**: Divide-and-conquer and recursive state exploration.
- **`Sliding window/`**: Subarray and substring optimization patterns.
- **`Stacks/`**: Monotonic stack problems, parenthesis matching, and expression evaluation.
- **`Tree/`**: Binary tree traversals, depth/height calculations, and path sums.
- **`Trie/`**: Prefix tree implementations and string searching.
- **`two pointer/`**: Opposing and parallel pointer techniques for arrays and strings.
- **`graph/`**: Graph traversal (BFS/DFS), shortest paths, and connectivity.
- **`related ques/`**: Additional hand-picked problems and variations (e.g., Sort Colors).
