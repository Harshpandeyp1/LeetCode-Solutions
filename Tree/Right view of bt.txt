Given the root of a binary tree, imagine yourself standing on the right side of it, return the values of the nodes you can see ordered from top to bottom.

 /**

* Definition for a binary tree node.
* public class TreeNode {
* ```
  int val;
  ```
* ```
  TreeNode left;
  ```
* ```
  TreeNode right;
  ```
* ```
  TreeNode() {}
  ```
* ```
  TreeNode(int val) { this.val = val; }
  ```
* ```
  TreeNode(int val, TreeNode left, TreeNode right) {
  ```
* ```
      this.val = val;
  ```
* ```
      this.left = left;
  ```
* ```
      this.right = right;
  ```
* ```
  }
  ```
* }
  */

class Solution {

```
// This method returns the nodes visible
// from the right side of the binary tree
public List<Integer> rightSideView(TreeNode root) {

    // This list stores the final answer
    //
    // Example:
    // [1, 3, 4]
    List<Integer> res = new ArrayList<>();


    // If the tree is empty,
    // there is no node visible
    if (root == null) {

        // Return an empty list
        return res;
    }


    // Create a queue for BFS traversal
    //
    // The queue stores complete TreeNode objects
    Queue<TreeNode> q = new LinkedList<>();


    // Add the root node to the queue
    q.offer(root);


    // Continue until every level has been processed
    while (!q.isEmpty()) {


        // Store the number of nodes
        // present in the current level
        int size = q.size();


        // Process all nodes of the current level
        while (size > 0) {


            // Remove the first node from the queue
            TreeNode node = q.poll();


            // Add the left child to the queue
            // for processing in the next level
            if (node.left != null) {
                q.offer(node.left);
            }


            // Add the right child to the queue
            // for processing in the next level
            if (node.right != null) {
                q.offer(node.right);
            }


            // Decrease the number of nodes
            // remaining in the current level
            size--;


            // When size becomes 0,
            // the current node was the last node
            // of this level
            if (size == 0) {

                // The last node of the level
                // is visible from the right side
                res.add(node.val);
            }
        }
    }


    // Return all rightmost nodes
    return res;
}
```

}
